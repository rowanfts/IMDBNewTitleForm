# IMDB - New Title

## Key Features
* restructures original form into digestable sections
* theme matching IMDB brand
* 'Shimeji' character reacts to form interactions, idle animations otherwise
* immediate error messages warn users of invalid input

## Setup Instructions
* Download all files from the Respository
* extract any .zip files and keep files in original location 
* run imdbMain.html
  * ex. open in VS Code and right click tab to run in browser

## Technologies and Frameworks
* HTML for website functionality
* JS for character behaviour
  * Heavily inspired by the original popular 'Shimeji' program
* CSS for website and character styling
